my_package.accessibility.combine_accessibility_matrices(matrices: Mapping[str, DataFrame]) → DataFrame[source]

Return an element-wise minimum of accessibility matrices.

Each matrix describes travel distances within one network (for example, drive and walk). The minimum is the best available route between two blocks when any of the networks can be used.

Return block boundary points closest to the road graph.

A block representative point can fall far from a road in large or elongated quarters. Sampling the boundary makes the connector to the graph shorter and more realistic.
