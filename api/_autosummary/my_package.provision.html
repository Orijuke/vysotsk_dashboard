Probabilistic service provision based on distance decay and capacity limits.

probabilistic_provision(blocks_df, ...[, ...])

Estimate expected service users with a gravity/Huff-style model.
my_package.provision.probabilistic_provision(blocks_df: DataFrame, accessibility_matrix: DataFrame, accessibility: float, demand: float | None = None, *, half_life_factor: float = 0.75, capacity_limit: bool = True) → DataFrame[source]

Estimate expected service users with a gravity/Huff-style model.

The probability of using a service decays exponentially with travel time. The decay half-life is accessibility * half_life_factor. Service choices are weighted by capacity, so a large service attracts more users than a small one at the same distance. The final number of users can be limited by service capacity.

Parameters:

  • blocks_df – Frame with population and capacity columns. An existing demand column takes precedence over population/demand.

  • accessibility_matrix – Square travel-time matrix indexed like blocks_df.

  • accessibility – Normative travel time in minutes, used to calibrate the decay.

  • demand – Normative demand per 1000 residents, matching BlocksNet conventions.

  • half_life_factor – Fraction of the normative time at which use probability halves.

  • capacity_limit – If True, scale incoming expected users when a service is over capacity.
