my_package.dashboard

Standalone interactive dashboard for urban indicator maps.

The builder produces a single HTML page with an Apple-inspired minimal UI. Only Leaflet and raster basemaps are loaded from the network; all thematic data (blocks, water, services) is embedded into the page, so the dashboard does not need a tile API key and works with any of the built-in basemaps, including a vector-only “no basemap” mode.
