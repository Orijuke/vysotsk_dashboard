Installation

The library can be installed with pip:

pip install git+https://github.com/vasilstar97/python-package-boilerplate@main

How to use

Use the library by importing classes from my_package:

from my_package.my_module_1 import MyClass

For more detailed use case see our examples.

Городской дашборд

В репозитории есть воспроизводимый пайплайн для Высоцкого городского поселения:

  • notebooks/vysokoye_research.ipynb — расчёт квартальных показателей;

  • notebooks/dashboard.ipynb — сборка автономного HTML-дашборда;

  • my_package/service_catalog.py — группы, алиасы, комбинированные индексы и оценка ёмкости сервисов по площади участка или типу;

  • my_package/accessibility.py — объединение доступности по дорожной и пешеходной сетям;

  • my_package/statistics.py — статистика и фильтры по кварталам;

  • my_package/dashboard.py и my_package/dashboard_template.py — дашборд.

Запуск:

jupyter nbconvert --to notebook --execute --inplace notebooks/vysokoye_research.ipynb
jupyter nbconvert --to notebook --execute --inplace notebooks/dashboard.ipynb

Результат сохраняется в notebooks/data/vysokoye/dashboard.html. Дашборд не требует API-ключей; тайлы загружаются с OpenStreetMap/Esri, остальные данные встроены в HTML.

Показатели

  • OSR — открытость застройки, а не доля озеленения.

  • green_share — доля лесов, парков и озеленённых территорий landuse.

  • area_accessibility — среднее пешеходное время доступности квартала (5 км/ч) по дорожной или пешеходной сети: для каждой пары кварталов берётся лучший маршрут.

  • green_access_m — расстояние до публичной зелени по дорожной или пешеходной сети; в пределах 500 м строится флаг green_access_500.

  • provision_strong_* — обеспеченность отдельными сервисами; для взаимозаменяемых услуг дополнительно считаются grocery (супермаркеты + магазины у дома) и parks (парки + заповедники). Для каждого сервиса в results.geojson также сохраняются access_time_*, service_demand_*, service_served_* и service_capacity_*; они показываются в подсказке квартала при выборе показателя обеспеченности.

  • Статистика — пересчитывается по произвольным фильтрам, показывает n, пропуски и помечает группы с n < 5.

Ограничения: население и ёмкость большинства сервисов импутируются, поэтому показатели нельзя использовать как официальную статистику. Ёмкость полигонов оценивается по ближайшему нормативному размеру участка BlocksNet, точечных объектов — по минимальному нормативу типа; источник указан в capacity_source.
